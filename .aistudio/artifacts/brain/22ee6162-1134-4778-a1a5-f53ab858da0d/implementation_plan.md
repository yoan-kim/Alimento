# Parábolas 99 — 한·스 완전 분리 및 양방향(문제↔답) 20문항 일일 학습·시험 시스템

기존 99개 성경 비유 학습 시스템을 개편하여 **첫 화면에서 선택한 언어(한국어 / Español)로만 100% 동작하는 단일 언어 몰입 인터페이스**, **라틴아메리카 에콰도르(`es-EC`) 스페인어 발음 엔진**, 그리고 **정방향(문제→답)과 역방향(답→문제)을 결합한 하루 20문항 학습 및 실전 시험 체제**를 구현합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 아래 3가지 핵심 설계 사항은 사전 질의응답을 통해 확정된 내용입니다.

- **Confirmed Decision 1 (2일차 이후 복습 10문항 구성)**: 매일 새로운 개념 5개를 정방향(`문제→답`) 5문항 + 역방향(`답→문제`) 5문항(**신규 10문항**)으로 출제하고, 1일차부터 전날까지 공부한 누적 범위에서 **무작위로 5개 개념을 추출하여 정방향 5문항 + 역방향 5문항(복습 10문항)**으로 구성해 **하루 총 20문항**을 학습·시험합니다. (1일차는 첫 10개 개념의 정방향 10 + 역방향 10 = 총 20문항)
- **Confirmed Decision 2 (역방향 출제 시 중복 답안 처리)**: `말씀(Palabra)`이나 `거짓 교리(Falsa doctrina)`처럼 동일한 답을 공유하는 개념이 역방향(`답→문제`)으로 출제될 때, **성구 힌트 없이 답안 텍스트만 제시**하며 채점 및 정답 확인 시 **해당 답안을 공유하는 모든 비유 질문·비유어를 복수 정답으로 인정**하고 함께 안내합니다.
- **Confirmed Decision 3 (언어 완전 분리 및 에콰도르 발음 지원)**: 첫 진입 화면에서 **`한국어`** 또는 **`Español`** 버튼을 선택하면 이후 모든 UI·메뉴·질문·답안이 선택한 언어로만 100% 표시됩니다. 에콰도르 스페인어(`es-EC` / 라틴아메리카 음성) 발음 듣기 버튼은 **`Español` 모드에서만** 표시됩니다.

## 1. Overview & Core Concept

- **What It Does**:
  - **초기 언어 선택 게이트**: 접속 즉시 `한국어`와 `Español` 두 개의 대형 선택 카드를 제시합니다. `한국어` 선택 시 스페인어 텍스트가 일절 섞이지 않은 순수 한국어 학습 환경이 열리며, `Español` 선택 시 한국어가 일절 섞이지 않은 순수 스페인어 학습 환경이 열립니다.
  - **양방향(정방향 + 역방향) 20문항 커리큘럼**:
    - **Day 1 (Día 1)**: `Q1 ~ Q10` 10개 개념 × 양방향(`문제→답` 10문항 + `답→문제` 10문항) = **총 20문항**
    - **Day 2 ~ Day 18 (Día 2 ~ Día 18)**: 일일 신규 5개 개념 × 양방향(**신규 10문항**) + 이전 학습 완료 개념 중 무작위 5개 개념 × 양방향(**복습 10문항**) = **총 20문항**
    - **Day 19 (Día 19)**: 마지막 신규 4개 개념(`Q96 ~ Q99`) × 양방향(**신규 8문항**) + 이전 학습 범위(`Q1 ~ Q95`) 중 무작위 6개 개념 × 양방향(**복습 12문항**) = **총 20문항**
    - **Day 20 (Día 20)**: 전 범위 99개 개념 중 무작위 10개 개념 × 양방향 = **총 20문항 종합 시험**
  - **20문항 실전 시험 모드**: 오늘 배정된 20문항(신규 10 + 누적 복습 10)을 서술형 입력 또는 4지선다 객관식으로 시험 치르고 점수를 확인할 수 있습니다.
  - **크롬 오프라인 단일 HTML 파일 저장**: 개편된 언어 분리 게이트, 에콰도르 발음, 양방향 20문항 시스템이 그대로 담긴 단일 `.html` 파일을 다운로드하여 크롬에서 언제든 실행할 수 있습니다.
- **Target Audience / Persona**: 한국어 또는 스페인어 단일 언어 시험 환경에 맞춰 성경 비유 99문항의 질문과 답을 양방향으로 완벽히 암기하려는 학습자.
- **Key Value**: 문제를 보고 답을 말하는 것뿐 아니라 답(의미)을 보고 원래의 비유(문제)를 역추적하는 훈련을 동시에 수행하여 암기 인출 속도와 정확도를 극대화합니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **Step 1 — 언어 선택 첫 화면 (Language Gate)**:
     - 화면 중앙에 `한국어` 버튼과 `Español` 버튼이 배치됩니다.
     - 버튼을 누르면 선택한 언어로 전체 애플리케이션이 진입하며, 상단 네비게이션 바에서 언제든 언어 선택 화면으로 돌아갈 수 있습니다.
  2. **Step 2 — 일일 20문항 양방향 학습 (Daily 20-Item Study)**:
     - 오늘의 20문항을 `전체 (20) / Todo (20)`, `신규 개념 (10) / Nuevos (10)`, `누적 복습 (10) / Repaso (10)` 또는 `문제→답 (10) / Pregunta→Respuesta`, `답→문제 (10) / Respuesta→Pregunta` 필터로 나누어 학습합니다.
     - `Español` 모드에서는 각 카드마다 라틴아메리카 에콰도르(`es-EC`) 억양으로 읽어주는 발음 듣기 버튼(`Escuchar pronunciación`)이 제공됩니다.
  3. **Step 3 — 20문항 실전 시험 (20-Question Exam)**:
     - 배정된 20문항(신규 10 + 복습 10)을 순서대로 또는 무작위로 섞어 시험을 봅니다.
     - 역방향(`답→문제`) 문항에서는 성구 힌트 없이 답안만 제시되며, 동일한 답안을 가진 비유어 중 어느 것을 입력·선택해도 정답으로 채점됩니다.
- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 단정하고 몰입감 높은 에디토리얼 학습 워크스페이스.
  - *Color Palette & Mood*:
    - 60% 캔버스 배경: 소프트 오프화이트 (`#F8FAFC`)
    - 30% 구조 표면: 화이트 카드 (`#FFFFFF`) 및 슬레이트 헤어라인 보더 (`#E2E8F0`)
    - 10% 포인트 액센트: 정방향/주요 액션 세룰리안 블루 (`#0284C7`), 역방향/복습 앰버 (`#D97706`), 완료 에메랄드 (`#059669`)
  - *Typography & Hierarchy*: 헤드라인 `Fraunces` 세리프, 본문 `Plus Jakarta Sans`, 문항 번호 및 통계 `JetBrains Mono` (`tabular-nums`).

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 에콰도르(`es-EC`) 스페인어 음성 우선 탐색 알고리즘**
  - *Chosen Approach*: Web Speech API의 `speechSynthesis.getVoices()` 목록에서 `es-EC`(에콰도르) 음성을 최우선으로 선택하고, 기기에 `es-EC` 전용 보이스가 없을 경우 인접 안데스·라틴아메리카 스페인어(`es-419`, `es-CO`, `es-PE`, `es-MX`, `es-US`) 순서로 폴백하며 `utterance.lang = 'es-EC'`를 명시합니다.
  - *Why*: 크롬 브라우저 및 운영체제마다 기본 설치된 TTS 음성 목록이 다르므로, 유럽 스페인어(`es-ES`, c/z 치간음 발음)를 배제하고 중남미 에콰도르식 발음(seseo)이 일관되게 출력되도록 보장합니다.
- **Decision 2: 역방향(`답 → 문제`) 중복 답안 자동 그룹핑**
  - *Chosen Approach*: 전체 99문항의 답안을 정규화하여 동일 답안 그룹(예: `말씀` 그룹 — Q2 씨, Q12 양식, Q18 저울, Q22 불, Q36 보화, Q38 물, Q43 그물)을 자동 매핑합니다. 역방향 문제에서는 성구 없이 답안만 제시하고, 정답 확인 및 서술형·객관식 채점 시 해당 그룹에 속한 모든 질문/비유어를 정답으로 인정합니다.
  - *Why*: 성구 힌트 없이 순수하게 답안 텍스트만 보고 역방향 문제를 풀더라도 불합리한 오답 처리가 발생하지 않으며, 연관된 비유어들을 한꺼번에 묶어 기억할 수 있습니다.

### Data Model & State
- **`AppLanguage`**: `'ko' | 'es' | null` (`null`일 때 초기 언어 선택 화면 렌더링).
- **`StudyCardItem`**:
  - `uid`: 고유 카드 식별자 (예: `Q1-FWD`, `Q1-REV`)
  - `questionId`: 원본 문항 번호 (`1 ~ 99`)
  - `direction`: `'FORWARD'` (`문제 → 답`) | `'REVERSE'` (`답 → 문제`)
  - `origin`: `'NEW'` (오늘의 신규 개념) | `'REVIEW'` (누적 학습 범위 랜덤 추출 개념)
  - `promptText`: 선택한 언어의 출제 텍스트 (`FORWARD`면 원래 질문, `REVERSE`면 성구 힌트 없는 답안 기반 역질문)
  - `expectedAnswers`: 선택한 언어의 정답 목록 (`REVERSE`일 때 동일 답안을 공유하는 모든 비유 질문 및 비유어 리스트 포함)
- **Interactive Component & State Mapping**:
  - **Language Gate**: 클릭 시 `language` 상태를 `'ko'` 또는 `'es'`로 설정하고 모든 UI 사전(`UI_TEXT[language]`)과 문항 데이터를 해당 언어로만 바인딩합니다.
  - **Daily 20-Item Generator**:
    - Day 1: `Q1~Q10` 10개 개념 → `FORWARD` 10개 + `REVERSE` 10개 = 20문항 생성.
    - Day 2~18: 해당 일차 신규 5개 개념(`FORWARD` 5 + `REVERSE` 5 = 10문항) + 이전 누적 범위(`1 ~ 이전 일차 마지막 번호`)에서 무작위 5개 개념 추출(`FORWARD` 5 + `REVERSE` 5 = 10문항) = 20문항 생성.
  - **20-Question Exam Runner**: 20문항 전체에 대한 진행 상태, 정오답 판별(역방향 복수 정답 자동 통과 포함), 최종 점수 집계를 수행합니다.
